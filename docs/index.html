The agent: what it does, and where a human stepped in

Five stages. Each agent stage runs from a prompt file in prompts/, so the exact instructions are checked into the repo. Accuracy figures are measured on the 30-app gold sample, 180 field judgments in total.

How it ran

The run used Claude Code subagents: 2 for pass 1 (memory only), 10 for pass 2 with one per category, 10 for pass 3 as adversarial verifiers, and 3 independent gold labelers. Web access went through the Firecrawl search and scrape tools. Composio coverage came from the public toolkit catalog. agent/research.py runs the same prompts end to end on the Claude API (tool runner plus Firecrawl REST) for anyone who wants to reproduce the run with their own keys.

Where a human was needed

    Verification: how we know it's right

    The gold sample is 30 apps, 3 per category, drawn with random.seed(2026) before any results were read. Three independent agents labeled them from vendor docs without seeing any pass output. Every disagreement between a pass and the gold labels was then re-opened on the vendor page and ruled on by the reviewer.

      Run it

      Source: GitHub repo. Every stage is a script or a prompt file.

      pip install anthropic requests
export ANTHROPIC_API_KEY=...  FIRECRAWL_API_KEY=...

python agent/composio_check.py                 # Composio catalog coverage (no key needed)
python agent/research.py pass1 --ids all       # recall-only baseline
python agent/research.py pass2 --ids all       # web-grounded research
python agent/check_evidence.py data/pass2 data/check_pass2.json   # loop 1
python agent/research.py pass3 --ids all       # loop 2: adversarial verifier
python agent/score.py                          # accuracy vs data/gold.json
python agent/build_site.py                     # -> docs/index.html, data.json, findings.md
      Built Nov 24, 2026. Every claim links to the vendor page it came from. No vendor accounts were created, and no authenticated calls were made.
